# 规格：空间 + 安全加固 + 分支上下文预算（2026-10-20）

来源：用户"利用这些（开源工具调研）为基础改进我的项目"；审计 `audit/flaws-2026-10-19.md`；借鉴 AnythingLLM（workspace）、BranchBook（摘要继承）。

## 用户故事
1. 我把一个要钻研的课题建成**空间**，写一句钻研目标；空间里的对话、资料、笔记互不串。
2. 我深挖到很多层，回答不会因为上下文爆窗口而失败，锚文本始终被模型看到。
3. 我的服务部署在公网，陌生人不能借走我的 key、不能拿 URL 入库扫内网、不能往我页面里塞脚本。
4. key 错/欠费时，我看到真实错误，而不是"模型返回了空内容"，失败文本也不会喂回模型。
5. 默认用 Inception Mercury，只需填 key。
